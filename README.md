# exec-mcp

让 ChatGPT 在你自己的 Windows、Linux 或 macOS 机器上完成开发工作。

exec-mcp 是一个自托管的 MCP 工具服务。ChatGPT 负责理解任务和决定下一步；
exec-mcp 负责操作本机文件、运行命令，以及连接你配置的其他 MCP 服务。
你不需要把项目迁移到新的开发环境，也不需要另开一个聊天界面。

> 以下介绍已经确定的产品方向，不表示这些能力已经交付。

## 你可以用它做什么

- 在现有项目中阅读和修改代码，运行测试、构建和 Git 命令。
- 并行执行独立工作，先整理工具结果，再把必要内容交给 ChatGPT。
- 在同一对话中使用自己配置的 MCP 服务，而不必预先加载全部工具说明。

工具说明使用中文。产品不提供自己的聊天界面或控制面板，继续使用 ChatGPT。
首版不提供内建 Skills 管理、问题表单或 ChatGPT 附件导入。

## 平台与连接

Windows、Linux、macOS 都是正式支持目标；Windows 指原生运行，不以 WSL 代替。
具体系统版本和 CPU 架构是否受支持，以今后发布版本的实际验证结果为准。

首版连接方式是 **OpenAI Secure MCP Tunnel**。
后续计划支持 Cloudflare Tunnel 和 Tailscale Funnel，目前不能据此视为已支持。
这些连接方式不会改变你操作项目的方式。

## 使用前需要知道

这是对你机器的真实访问，不是只读演示，也不是命令沙箱。
连接的助手可以使用运行服务的操作系统账户所拥有的文件和执行权限。
应以合适的普通账户运行，只连接自己信任的客户端和 MCP 服务。

本地服务默认只监听回环地址。不要把无认证的服务直接暴露给公网，
也不要认为配置了隧道就自动获得了客户端认证。

仓库留在你的机器上，但返回给 ChatGPT 的代码、日志和工具结果会进入相应的服务链路；
“自托管”不等于“数据从不离开机器”。请自行控制敏感信息和外部服务权限。
