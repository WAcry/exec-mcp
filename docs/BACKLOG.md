## 1. 公共 npm 安装与启动后的 Web UI

状态：已完成 Web UI 本地控制台开发（支持 Light/Dark 模式、0.0.0.0 动态随机密钥授权、127.0.0.1 免密访问、ChatGPT 实时调用流与 Session 分组分页、子调用耗时与详情、下游 MCP/Skills/终端监控）；待公开发布 npm 包。

计划发布到公共 npm registry，让用户通过 **npm install 安装、命令行启动**。
Windows、macOS、Linux 都沿用这一方式，不要求额外的桌面安装器。
正式发布前，README 继续提供当前真实可用的源码安装步骤，不提前写成公共包已可安装。

启动服务后计划提供 Web UI，让配置与连接、鉴权辅助、运行状态，以及查看 ChatGPT 的
工作和命令调用流等操作更友好。其他界面能力只在确有价值时加入，具体范围留待实施时收敛；
它不是替代 ChatGPT 的另一套聊天客户端。

前置条件：确定公开许可、npm 发布权限与发布流程，验证公共包安装和跨平台命令行启动；
开发 Web UI 前明确本机/远程访问及鉴权边界，调用流和日志展示不得泄漏凭据。

这是一项延后计划，不将 UI 提前变成当前执行链路的依赖，也不恢复 request_user_input、
子 Agent 等暂不计划实现的能力。
