# ADR-003：结果与执行生命周期

状态：生效。更新：2026-09-22。

## 结果只表达一次，Agent 决定展示什么

不同时发送 structuredContent 和等价 JSON 的文本镜像。下游只移除可无损证明重复的文本，
保留独立说明、isError、媒体、资源和内容块元数据；宿主私有的顶层 _meta 不进入模型。
大整数、重复键、数字表示不能经有损 parse/stringify 后被当作相同内容。
结构化字段存在不代表成功，也不能把字段缺失与合法 null、数组、标量混同。

本机函数交给 JS 原值，下游保留 CallToolResult；text/image/audio/generatedImage 决定模型可见内容。
显式输出不再次复制成结构化镜像；导出链接独立附带，见 [ADR-005](adr-005-file-transfer.md)。
这种去重优先服务目标 ChatGPT 链路，不为没有实际消费者的兼容性恢复双份结果。

通用大结果不自动落盘：那会引入重读、路径解析和另一套结果生命周期。
Agent 可先在 Code Mode 筛选原值、store 后分段 load，或明确写入文件。
最终响应采用保守 UTF-8 字节边界；它来自目标链路实测，不是永久通用的 ChatGPT token 上限。
超限保留首尾并提示，丢弃部分不由后续 wait 补发，截断文本也不保证仍是合法 JSON。

显式 exec.max_output_tokens 与 wait.max_tokens 各自缩小本次文本预算，外层参数优先于首行 pragma；
wait 不继承 exec 的显式值。token 使用轻量估算，状态/句柄/媒体保留，仍计入相应最终载荷边界。
嵌套工具不提前套模型文本预算；真实传输边界仍独立生效，超限可能在原始值到达 JS 之前失败。
输入过大可在操作前拒绝，结果过大则可能已产生副作用，不能自动重试。

用户补充只使用最终响应的剩余额度，与原结果共用文本通道，不挤压普通结果；
完整消息放不下则排队，见 [ADR-010](adr-010-session-notes.md)。
默认数值及可调项见[配置指南](configuration.md#容量与临时状态)；schema/实现是精确边界的事实来源。
单次编码保护不是整个进程的内存上限，SDK 缓冲、并发和短期副本都可能增加占用。

## 终端日志有界，但不自动保存全部日志

每个终端独立保留未读头部和滚动尾部，溢出丢弃中间，并返回省略位置及字节计数。
按字节而不是行数计量，避免巨大单行绕过；已读头部不重复返回。
限制在接收阶段生效，避免无限积压，也不通过暂停全部会话来让 A 的刷屏阻塞 B。
需要完整日志或数据的命令可显式重定向文件；不管理用户生成文件的大小或磁盘配额。

已退出且久未读取的终端记录可过期，正在运行的进程不因该记录策略被终止。
缓冲保护不包含系统管道/PTY 和在途副本，不声称是 Node 进程的严格 RSS 上限。

## cell 与终端分离，等待不是回滚

每次 exec 创建独立 V8 isolate。仍运行的脚本以 cell_id 续等或终止，
命令返回 session_id 后由独立终端生命周期持有，可跨 exec 使用。结束 cell 不等于结束已交回句柄的进程。
句柄都是临时标识，不是任务持久化、权限或跨重启恢复保证。正常关闭清理自有进程，异常退出不保证撤回副作用。

write_stdin 对齐固定 Codex 的收集窗口：非空写入较短，空输入可收集较长窗口；
[上游收集器](https://github.com/openai/codex/blob/ebc05da3bdb76f25861e7cb418bd06d28cadc609/codex-rs/core/src/unified_exec/process_manager.rs)
收到日志后继续收集，到截止时间或进程结束才返回，并非任意新日志就结束工具调用。
窗口在取得终端并完成写入/调整后开始，排队和 stdin 背压不应耗尽它；日志不重置截止时间。
显式 0 立即读取作为已有扩展保留。更长等待不扩大缓冲，也不会自动消费并输出无限日志。

内层工具可以运行超过单次外层等待窗口；exec 可先交回 cell，再由 wait 观察。
外层 wait 默认及最大 110 秒，以目标 connector 超时不少于 120 秒为工程假设，预留传输余量，
不把它宣传成上游保证或任务执行期限。完成、主动 yield 或终止可以提前返回。
不另建 sleep 工具、后台模型轮询或持久任务调度。

取消一次 wait 仅取消观察；终止 cell 会请求取消尚未完成的嵌套调用，
已经交回 session_id 的终端仍需显式终止。观察者结束后解除监听，不消费尚未交付的输出。
取消、断连、host 故障和结果失败都不回滚已发生操作；恢复连接不能自动重放脚本或下游调用。
未 await 的 Promise 不构成可靠后台任务；notify 的宿主消息注入未接入，不以普通 MCP 通知冒充。

## store/load 复用原生 host，不再造缓存产品

同一 ChatGPT 对话复用原生 session，跨 exec 保留的是 host 内的序列化数据，不是普通 JS 变量或磁盘数据。
使用固定 host 的同步 store/load，不修改二进制、不另设逐 key 协议、对话小配额或自定义 delete/clear/stats。
既有传输上限不等于存储总量；固定版本忽略的 heap 配置字段不能当作有效保护。

每个 cell 读取启动快照，load 返回副本；写入在 cell 完成时合并，脚本错误前的写入也可能提交，
终止未提交 cell 不发布这些写入。并发同键非事务，store/load 也不是运行中 cell 的实时消息通道。
单个 cell 收尾不关闭同一对话其他 cell；完成结果仍能通过原 cell_id 收取。

对话归属使用宿主 openai/session 的摘要，不以连接、单轮消息或工作目录区分。
缺少标识时普通执行可用，store/load 明确失败，不退回全局共享存储。该关联不是身份认证。

## 回收旧状态不能永久损坏对话

宿主对话标识与原生 session 代次分离：回收先解除旧绑定，再异步关闭；
同一对话可立即创建干净的新实例。旧关闭回调、晚到结果和租约只能影响旧代次，
不能按相同对话名删除新实例。旧 cell 不路由到新 session，也不自动重播。

只观察自有 Code Mode host 的近似 RSS/working set，不用 Node heapUsed 代替，
不统计或限制浏览器、编译器等用户子进程树。测量失败不当作超限，过期样本不能作用于新 host。
正常时所有 cell 收尾后保留空闲会话；压力下先按进入空闲时间 FIFO 回收，再测量。
没有空闲候选且仍超高水位时，才回收最久未使用的活动 session，接受其多个 cell/store 一起丢失。
已低于高水位时不为凑低水位继续牺牲活动会话；一轮只处理开始时存在的代次，不追杀刚恢复的新实例。

只有关闭故障且压力仍高，或状态释放后内存仍高时，才以共享 host 重启兜底。
这会影响其他原生会话，必须明确报告；无法确认旧 host 终止时不盲目并开新 host，后续仍可重试恢复。
这是宽松压力策略，不是 OS 硬限额或任意恶意程序都不会耗尽内存的保证。
独立终端不因原生存储回收被顺带杀掉，持久数据由调用方显式写文件。

## 状态和诊断不夸大结果

Script completed 表示 JS 编排完成，不表示全部命令成功。Shell 退出码保持原生语义，
stderr 字节数是辅助信息，不自动等同失败；PTY 不虚构分流。子调用失败不变成会话永久红色告警。
原生 SyntaxError 后才辅助解析实际收到的源码，给出指纹及可定位时的片段；
不预执行修改后的源码，也不让辅助解析器成为 V8 的前置语法门槛。

generatedImage 只输出已有 data URL 和说明，不调用生成 API、不下载 URL 或自动保存文件。
媒体沿用固定 host 原生规则，文本预算不再另造一套音频/图片检测或过滤流程。
