# ADR-005：文件传输与交付边界

状态：生效。日期：2026-09-17。

## 决定与原因

import_file/export_file 仅通过 exec 编排。
ChatGPT 文件绑定放在可选的 exec.files，通过 openai/fileParams 标记；
流式导入和独立资源交付不为传输额外引入模型工具或任务。
完整字节不穿过 V8、模型文本或 store；不让 Agent 手工搬运 Base64。

文件输入绑定必须在顶层，不能解析 source 字符串后猜测文件引用。
机器端持有临时下载凭据；exec 脚本只用本次文件数组的零基索引。
未使用的文件不自动下载，Web 审计不记录任何入口的签名下载 URL。
普通执行不依赖附件；无文件或索引不符时明确失败，不猜测其他消息中的附件。
文件 schema 声明四个官方字段，仅 download_url/file_id 必填；工具说明与原始宿主数据区分。
输入依据：[OpenAI 文件参数](https://developers.openai.com/plugins/reference#define-file-inputs)。

## 导出生命周期与工具表面

不再向模型提供 revoke_file，也不保留隐藏别名。个人日常交付通常只需导入与导出，
短期快照已自动过期；偶发的提前撤销不值得常驻在每次 exec 的工具目录里。
保留 Web 控制台的显式撤销以及内部失败清理、到期/关闭清理，用户仍能提前收回公开 URL 的后续访问。
这是模型工具表面的收敛，不是删除资源生命周期或改变已经开始的下载能否收回的语义。

## 导入不留下半个目标文件

使用 HTTPS，不跟随重定向；直连固定已验证的公网 DNS 地址，显式代理接管目标 DNS 与路由，见 [ADR-008](adr-008-environment-and-proxy.md)。
不回显签名 URL，不把它放进 JS 环境、工具目录或持久日志。
流式写入同目录临时文件，计算长度与摘要，再发布到明确目标；默认不覆盖。
覆盖、取消和发布失败不得假装是可回滚事务；不能为了方便而开放任意下载 URL 参数。
来自宿主的 URL 格式并非独立身份认证，真实授权仍来自私有 MCP 入口。

## 默认私有资源，公开 URL 必须显式选择

参考 [WebCodex 文件桥](https://github.com/yyjeqhc/webcodex/blob/main/docs/MCP.md#chatgpt-file-bridge)，
默认返回原生 ResourceLink，宿主通过 resources/read 取文件；不要把链接对象 text() 后冒充原生交付。
固定 host 只负责 JS、文本和媒体；文件链接由每个 cell 独立队列追加到 exec/wait。
不修改上游协议，不解析特殊文本标记。文本预算不能删除文件引用；撤销的待返回引用不再交付。

导出创建私有、短期文件快照，源文件后续变化不影响内容；复制期间检测到变化则不发布。
快照属于明确文件交付，不是大工具输出自动落盘。资源记录独立于 cell，支持多次读取，
到期/撤销立即拒绝新读取，已开始或已完成的下载不能收回；正常关闭清理快照，重启不恢复链接。
不列出文件或开放任意路径的读取端点。临时文件使用操作系统的私有临时目录，异常退出后的
残留文件不可通过旧链接访问，可能需要系统临时目录清理。

资源读取的授权边界是本实例受信任的单操作者 MCP 入口。resources/read 不保证携带对话标识；
双方都提供标识时拒绝跨对话读取，省略时仍依赖同一个私有入口，不把该可选字段冒充认证。
资源 URI 不能拿到公开下载端口使用。若扩展到多人或公开 MCP，必须接入真实调用方身份后再开放。

URL 模式需要操作者预先配置真实 HTTPS 基址，并显式选择 delivery=url。
独立回环端口只提供指定导出的 GET/HEAD/单范围读取，使用不同的高熵限时 bearer token；
不提供 MCP、目录浏览、上传或任意本机路径读取。禁止把无认证 MCP 端口顺便转发到公网。
下载强制 attachment、nosniff 和禁止执行的 CSP；链接可转发，权限与此风险必须在工具说明中明确。
文件下载入口不自动配置 Tunnel 或对象存储，也不会在 resource 失败时偷偷降级为公开 URL。

## 接受的限制

MCP binary resource 仍是 Base64，SDK 可能缓冲完整响应，所以资源模式采用独立的宽松大小边界，
并对并发读取做字节预算；URL 模式走原始字节流，用于更大的文件。
快照配额计入管理开销，不能靠大量空文件无限创建导出记录；具体数值在代码与用户配置说明中维护。
传输有自己的取消和绝对期限，不继承一次 wait 的 110 秒窗口。

协议资源可读、浏览器可下载、ChatGPT 附件展示和 sandbox 挂载是不同验证层次。
服务器测试不冒充真实 ChatGPT 文件绑定/展示测试；不提供或伪造 sandbox 路径，也不承诺挂载。
