# ADR-009：可选的本机 Web 管理控制台

状态：生效。日期：2026-09-18。

## 管理现有运行时，不建设第二个 Agent

`exec-mcp serve` 可以同时启动只读为主的 Web 管理控制台，用于查看调用审计、会话摘要、
原生 session/内存、终端缓冲、Skills、下游 MCP 和导出产物，并提供清空审计、撤销产物等少量管理动作。
直接工具和 exec/wait 按实际工具名归档；列表/筛选/详情支持命令与补丁原文，不把直接调用伪装成 JS 或 wait。
所有入口都有独立的输入参数视图，原文字段与其余参数同时可查；保留 0、false、空字符串及实际参数名。
无子调用的直接操作不展示空调用流；正在观察的在途调用更新其详情，已返回句柄不等于底层任务已经完成。
它不是另一套聊天界面，不调用模型，不增加顶层 MCP 工具，也不成为 exec/wait 执行链路的依赖。
Web 启动失败只报告警告，MCP 服务继续运行；用户可用 `[web].enabled=false` 完全关闭。
关闭时不采集调用参数、源码、子调用或结果的审计副本；Web 启动失败后也清空并停止采集，
不能把“页面没有运行”误解为仍可在后台保留敏感观察数据。

前端作为 npm 包内的静态资源构建，不在运行时加载第三方字体、脚本或分析服务；
CI 必须单独类型检查前端，并通过生产构建和独立 tarball 安装验证。

## 默认仅本机，局域网必须显式开启

默认监听 `127.0.0.1:8893`。8891 保留给 MCP，8892 可由独立文件下载入口使用；
端口冲突明确失败，不自动扫描并占用其他端口。只有用户把 `[web].host` 明确设置为
`0.0.0.0` 或 `::` 时才开放局域网；这不是公网入口，也不由 Cloudflare/Tailscale MCP Tunnel 自动发布。

本机免密访问同时要求 TCP 对端和 HTTP Host 都是回环地址，防止 DNS rebinding 把浏览器的本机权限
变成任意站点权限。浏览器 API 只接受同源请求；响应设置 CSP、拒绝嵌入、禁止 Referrer，
管理写操作还要求 UI 专用请求头。CLI/curl 无 Origin 的请求仍可使用，但需要满足同一认证边界。

局域网模式每次启动生成新的高熵密钥。CLI 打印的引导链接把密钥放在 URL fragment，
fragment 不会随 HTTP 请求或 Referrer 发送；前端只用它换取 `HttpOnly; SameSite=Strict` cookie，
随后立即从地址栏移除，不存入 localStorage。查询参数不作为认证来源。
换新密钥和在文件管理器中定位配置仅允许可信回环请求；换新后旧 cookie 立即失效，
已经建立的 SSE 观察连接也立即断开，必须用新密钥重新认证。
当前 UI 使用 HTTP，不适合不可信 Wi-Fi 或直接公网暴露；需要远程管理时应另建受保护的 HTTPS 边界。

## 审计是有界的临时观察数据

调用审计只存在于当前进程内，重启后丢失，不写磁盘。对话只显示与原生 session 相同的不可逆摘要，
不展示原始 `_meta["openai/session"]`。列表返回小型摘要，详情按需读取；SSE 只发送失效通知和 ID，
不重复广播完整源码、参数或结果。
响应详情记录最终出口处理后的 MCP 结果，再作有界审计裁剪；不是未包装的内部对象，也不承诺完整抓包。
裁剪提示在所有详情页可见；导入附件只记录文件名、类型与大小，签名下载地址及不透明凭据不进入审计。

记录数量、单次文本、子调用数量和字段体积都有宽松上限；过大内容保留首尾并明确标注，
中间子调用采用保留最早和滚动最新的方式。该裁剪只影响 Web 审计副本，不改变 MCP 实际返回、
终端输出、文件产物或副作用。配置界面只返回安全摘要：凭据值、header/env 值和命令参数不进入浏览器；
但受信任用户主动运行的命令及工具结果本身可能包含敏感信息，因此控制台仍属于高权限界面。

## 管理动作沿用实例边界

撤销导出产物由已经认证的实例管理端点按不透明导出 ID 完成，不伪造 ChatGPT 对话 scope，
也不放宽 MCP 资源读取的 scope 规则。控制台不提供任意命令输入框、store 编辑器或 session 强杀按钮；
新增破坏性能力前必须重新审视认证、竞态和副作用说明，不能因“只在 UI”而绕过现有生命周期语义。

## 现有配置开关与执行服务重启

控制台可以切换已有 MCP、已发现 Skill、默认 login 和 Web enabled；不增加通用配置编辑器或新增服务界面。
只定点修改 TOML 布尔值，保留注释和其他数据；完整配置校验、版本比较及同目录原子替换避免静默覆盖并发编辑。
保存与生效分开；重启先读有效配置再停止旧运行时，重建工具连接、原生内存和终端，不备份临时执行状态。
重启失败时保留 Web 管理入口和错误，修正后可重试；重复点击合并为一次，关闭期间不会重新开监听。
认证的 Web 写入边界保持不变；控制台专注观察与管理执行服务，不提供人机问答入口。

会话组展示当前是否尚有执行，不用累计错误次数制造永久告警；审计裁剪只在对应详情标注，不占仪表盘计数卡。
界面区分“脚本完成”和子命令结果，不把所有异常当成整个会话故障。
